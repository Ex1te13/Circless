# Хранилище кружков

Telegram-бот для хранения видеосообщений (кружков) с тегами и галереей в виде Telegram Mini App.

## Принцип работы

Пользователь пересылает боту кружки и назначает им теги. Сохранённые кружки можно просматривать по тегам в чате или в галерее.

```
Telegram ──webhook──▶ Vercel (index.py → core/web.py)
                        ├── core/handlers.py    логика бота
                        ├── webapp/index.html   галерея (Mini App)
                        ├── core/db.py ───────▶ Supabase Postgres
                        └── core/storage.py ──▶ Supabase Storage
```

- **Приём сообщений.** Telegram передаёт каждое обновление на адрес `/api/telegram` (webhook, по одному обновлению за раз). Запрос проверяется по секретному заголовку.
- **Хранение.** Видеофайлы остаются на серверах Telegram. В базе данных хранятся `file_id`, теги, даты и состояние бота: текущая пачка кружков и сообщение с тегами.
- **Пачки.** Кружки, пересланные подряд, объединяются в одну пачку с общим сообщением для выбора тегов.
- **Подборки в чате.** Бот отправляет кружки по 10 штук с заголовками дат. Все сообщения подборки запоминаются, чтобы её можно было удалить из чата.
- **Галерея.** Mini App получает список кружков через `/api/data`. Запросы подписаны Telegram (`initData`) и проверяются на сервере. При первом просмотре видео копируется в приватное хранилище Supabase, а браузер получает временную подписанную ссылку.
- **Доступ.** Ботом пользуются только пользователи из `ALLOWED_USERS`. Данные каждого пользователя разделены.
- **Фоновые задачи.** Supabase `pg_cron` вызывает `/api/ping` каждые 4 минуты, чтобы функция на Vercel не остывала. Vercel Cron раз в сутки вызывает `/api/cron`, чтобы база не засыпала, и удаляет устаревшие записи.

## Структура

| Файл | Назначение |
|---|---|
| `core/handlers.py` | Команды, кнопки, сохранение кружков, подборки |
| `core/web.py` | Webhook, API галереи, выдача видео, cron |
| `core/db.py` | Доступ к базе данных (PostgreSQL, в тестах SQLite) |
| `core/storage.py` | Работа с Supabase Storage |
| `webapp/index.html` | Галерея |
| `deploy_setup.py` | Разовая настройка: таблицы, webhook, фоновая задача |

Настройки задаются переменными окружения, список приведён в `.env.example`.
